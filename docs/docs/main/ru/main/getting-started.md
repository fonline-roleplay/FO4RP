# Установка {#installation}

Следующие инструкции основаны на некоторых общих предположениях:

- У вас установлен `git`
- Вы имеете базовые навыки работы с файловой системой и текстовыми конфигами

## Скачивание и правильная структура папок {#download-and-folder-structure}

1. Создайте новую папку с любым названием (но чтобы она не имела буквы не-латинского алфавита, а также пробелов и прочих спец-символов в пути)

2. Перейдите в эту папку, и откройте в ней консоль, выполните следующую команду

   ```sh
   git clone --recursive https://github.com/fonline-roleplay/fo4rp Server
   ```

   Команда `git clone` создаст локальную копию репозитория сервера в папке `Server` и скачает актуальную копию.

3. Перейдите в папку `Server`, скопируйте `tnfFonlineServer.cfg` и дайте новой копии название `Server.cfg`

4. Вернитесь в ту папку, в которую клонировали `Server`, создайте новую папку `Client`

5. Скачайте [программу для обновления клиента](https://cdn.discordapp.com/attachments/1319029614776946808/1500537393776693531/TLJ_updater.exe?ex=6aa62919&is=6aa4d799&hm=06de2e47f526c8de853aaee8a9ad26f5b68ad1c58f9ad70454ee95ff0489a6dd&) и положите её в папку `Client`, запустите и ожидайте надписи `Done. Press Enter to exit.`, нажмите Enter и закройте консоль.

6. Теперь перейдите в папку `Server` и запустите `Server64.exe`, нажмите `Start Server`, после этого попробуйте подключиться с клиента по адресу `localhost:4000`

## Запуск маппера {#running-mapper}

1. Перейдите в папку `Server/Tools/Mapper/`

2. (Опционально) Найдите и откройте `Mapper.cfg` в любом удобном редакторе текста, настройте пути к серверу и клиенту, если стандартные пути не работают

3. Запустите `Mapper64.exe`
